Company Landing Page

This is a modern Company Landing Page built with Vite + Remix.
It is designed to be fast, responsive, SEO-friendly, and easy to customize for any business or startup.

✨ Features

⚡ Blazing Fast – Powered by Vite
 for instant builds and HMR.

🎨 Modern UI – Built with Remix
, optimized for routing & performance.

📱 Responsive Design – Works perfectly on desktop, tablet, and mobile.

🔍 SEO Optimized – Meta tags, Open Graph, and sitemap included.

🌙 Dark/Light Mode – Ready for theme customization.

🛠 Easy to Deploy – Works on Vercel, Netlify, Cloudflare, or any Node.js server.

🚀 Getting Started
Requirements

Node.js (>=18.x)

npm, pnpm, or yarn package manager

Installation
# Clone the repository
git clone (https://github.com/Aderito-Muffins/Company-Landing-Page-Tech.git)

# Navigate into the project
cd Company-Landing-Page-Tech

# Install dependencies
npm install

# Start development server
npm run dev


The app will be available at http://localhost:3000.

🛠 Tech Stack

Frontend Framework: Remix + Vite

Styling: TailwindCSS (or custom CSS modules)

Animations: Framer Motion (optional)

Deployment: Vercel / Netlify / Cloudflare Pages
